    Privacy

    Name columns (first initial, last name) are recognised and dropped as soon as a file is read. Patient IDs are replaced by a one-way pseudonymous key, so the dashboard never stores or exports the original ID. This is pseudonymisation, not anonymisation: do not upload real patient data to a public or shared copy of this dashboard.

    Data held in this browser

    Uploaded data is saved in this browser only (IndexedDB). Other visitors and other devices do not see it.

    How to use this dashboard

    1. Start on Overview. KPI cards, key findings, the attention table and recommended actions summarise the current view.
    2. Filter. Choose months, referral department, age group, gender, race or admission status in the bar at the top. Every chart, table, KPI, report and export follows the filters. Click a chip to remove a filter, or use Reset filters.
    3. Set the waiting-time target. "Wait target" changes what counts as a long wait everywhere (default 30 minutes).
    4. Investigate. Hover any chart for exact values. Click a month or a department to filter to it. Use ⤢ to view a chart full screen.
    5. Add data. On Add data, upload a file, read the check, then apply it. Everything recalculates straight away. Undo or reset at any time.
    6. Take it away. Generate Analysis Report creates a PDF of the current or full analysis; Download Analysis Data exports the records being analysed (CSV or Excel).

    Data and its limits

    • Source: . One row per ED visit, 9,216 visits from April 2023 to October 2024. The data appears to be a synthetic practice dataset: distributions are almost perfectly even, so expect few real differences between groups.
    • One waiting-time figure per visit: the data does not say which stage it measures (for example arrival to first clinician). It is used as recorded.
    • Satisfaction: about 73% of visits have no score. Scores describe respondents only and are never imputed.
    • Referral 'None' means no referral to a specialty department. Gender 'NC' means not specified.
    • Patients CM is kept but not analysed because its meaning is not documented.
    • Associations only: tests show whether differences are larger than chance; they do not show cause and effect.
    • Where your data is kept: uploads stay in this browser's IndexedDB. Clear them with "Reset to the original dataset" or by clearing site data.
